常见问题解答

Firefox 是免费的吗？
是的，Mozilla Firefox 是完全免费的开放源代码软件。您可以自由下载、使用和修改，没有任何隐藏费用。
Firefox 会收集我的浏览数据吗？
默认情况下，Firefox 会收集一些匿名统计数据以帮助我们改进产品。您可以在设置中关闭“遥测”功能，进一步保护隐私。
如何从其他浏览器迁移数据？
Firefox 提供了“导入向导”，可以帮助您轻松从 Chrome、Edge、Safari 或 Internet Explorer 导入书签、密码和浏览历史记录。
